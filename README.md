## 📋 Overview

This is a **self-paced, interactive JavaScript bootcamp** designed for absolute beginners. Built like a real coding bootcamp, it covers everything from variables to async programming over **12 weeks** of structured learning.

Unlike passive video courses, this bootcamp gives you an **interactive code playground** where you write and run JavaScript directly in your browser — no setup required.

## 🎯 What You'll Learn

| Module | Topics | Duration |
|--------|--------|----------|
| **1. Fundamentals** | Variables (`let`/`const`), 7 data types, operators, type coercion | 2 weeks |
| **2. Control Flow** | `if/else`, `switch`, ternary, `for`/`while` loops, FizzBuzz | 2 weeks |
| **3. Functions** | Declarations, expressions, arrow functions, scope, closures, HOFs | 2 weeks |
| **4. Arrays & Objects** | `map`/`filter`/`reduce`, destructuring, spread/rest, nested data | 2 weeks |
| **5. DOM & Events** | Selecting elements, event listeners, forms, event delegation | 2 weeks |
| **6. Async & ES6+** | Promises, `async/await`, Fetch API, modules, optional chaining | 2 weeks |

## 🚀 Getting Started

### 30-Second Start

1. **Open** [`playground.html`](playground.html) in Chrome/Edge
2. **Type** `console.log("Hello, World!");` in the left panel
3. **Click** ▶ Run (or press `Ctrl+Enter`)
4. **You just wrote JavaScript!** 🎉

### Weekly Routine

1. **Read** one chapter from the current lesson module
2. **Type** the code examples into the playground
3. **Solve** the corresponding exercises
4. **Check** your answers against the commented solutions
5. **Build** the mini-project when you finish the module

## 💡 Why This Bootcamp?

- **No setup required** — just open the HTML file in a browser
- **Learn by doing** — every concept has runnable code examples
- **Beginner-friendly** — assumes zero prior knowledge
- **Self-paced** — follow the 12-week schedule or go at your own speed
- **Real projects** — build practical applications, not just toy examples
- **Mental models** — analogies that make concepts stick

## 🛠️ Prerequisites

- A computer with a modern web browser (Chrome, Edge, or Firefox)
- A text editor (VS Code recommended, but any editor works)
- **No prior coding experience required!**
