# 🚀 How to Start Learning JavaScript

## Step 1: Open the Playground
Open **`playground.html`** in your browser (Chrome or Edge recommended).
- Left side: where you type JavaScript code
- Right side: shows the output when you click "Run"
- Press `Ctrl+Enter` as a shortcut to run your code

## Step 2: Start Lesson 1
Open **`lessons-javascript/01-fundamentals.md`** in VS Code.

Read each chapter and **type the code examples into the playground** — don't just read them! Actually type them and run them to see the output.

## Step 3: Do the Exercises
After reading Lesson 1, open **`exercises/01-exercises.js`** in VS Code.

Copy the exercise code into the playground and try to solve each one. The solutions are at the bottom of the file — but try for at least 10 minutes before peeking!

## Step 4: Repeat for Each Module

| Order | File | What to Do |
|-------|------|------------|
| 1️⃣ | `01-fundamentals.md` → `01-exercises.js` | Variables, data types, operators |
| 2️⃣ | `02-control-flow.md` → `02-exercises.js` | if/else, loops |
| 3️⃣ | `03-functions.md` → `03-exercises.js` | Functions, scope, closures |
| 4️⃣ | `04-arrays-objects.md` → `04-exercises.js` | Arrays, objects, map/filter/reduce |
| 5️⃣ | `05-dom-manipulation.md` → `05-exercises.js` | Buttons, forms, events |
| 6️⃣ | `06-async-es6.md` → `06-exercises.js` | Fetch API, promises |

## Step 5: Try the Calculator Project
Once you've finished Module 3-4, open **`projects/calculator/index.html`** in your browser and play with it. Then try reading the JavaScript code at the bottom of that file to understand how it works!

## 🎯 Your First 30 Minutes

1. Open `playground.html` in your browser
2. Open `lessons-javascript/01-fundamentals.md` in VS Code
3. Scroll to **Chapter 2** ("Your First JavaScript")
4. Type `console.log("Hello, World!");` in the playground
5. Click **Run**
6. You just wrote your first JavaScript! 🎉

Then continue reading through Chapter 3 (variables), typing each example into the playground as you go.
